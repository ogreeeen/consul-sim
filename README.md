# コンサル転職シミュレーター

実在のファーム名をもじった架空のコンサルファームを受ける、面接シミュレーションゲーム。

- プロフィール（名前・年齢・年収）→ 企業選択 → 現職 → 自己PR → 志望動機 → 面接質問3問 → 逆質問
- 不合格条件を満たした時点で不合格（例：戦略ファームは31歳以上で即不合格）
- 企業ごとに、志望動機などに「その会社専用の選択肢」が紛れ込む
- 不合格画面・内定画面から、ブログの対策記事と無料相談（ogumatoshihiro.com/lp）へ案内

ゲーム本体は `app/src/main/assets/index.html`（企業・質問・不合格条件もこの中）。
